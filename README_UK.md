# xlsx2txt

**Двосторонній конвертер між Excel (.xlsx/.xlsm) та текстовим JSON-форматом з повною підтримкою round-trip.**

На відміну від простих екстракторів тексту, xlsx2txt зберігає все — формули, стилі, об'єднані клітинки, VBA-макроси — і може повністю відновити оригінальний Excel-файл.

## Навіщо?

- 📊 **Git-friendly** — зрозумілі діфи для Excel-файлів
- 🔄 **Round-trip** — xlsx → text → xlsx без втрати даних
- 👁️ **Людиночитабельний** — JSON-формат для зручного перегляду
- ✅ **Верифікація** — вбудована перевірка цілісності

## Встановлення

```bash
pip install xlsx2txt
```

## Швидкий старт

```bash
# Експорт Excel у текстовий формат
xlsx2txt export report.xlsx ./report/

# Редагуйте JSON-файли або комітьте в Git
git add report/
git commit -m "Оновлення Q1 2025"

# Відновлення Excel-файлу
xlsx2txt import ./report/ report_new.xlsx

# Перевірка цілісності
xlsx2txt verify ./report/
```

## Структура виводу

```
report/
├── manifest.json           # Метадані
├── data/
│   ├── workbook.json       # Властивості книги
│   ├── sheets/
│   │   ├── _index.json
│   │   └── Sheet1.json     # Клітинки, формули, розміри
│   └── styles/
│       ├── fonts.json
│       ├── fills.json
│       └── ...
├── vba/                    # VBA-код (для .xlsm)
│   └── modules/*.bas
└── _verify/                # Дані верифікації
    └── checksums.json
```
